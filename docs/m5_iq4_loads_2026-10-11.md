# IQ4_XS aligned load screening on Apple M5

The [decode profile](m5_native_decode_profile_2026-10-10.md) identifies
IQ4_XS projections as a major target. Three private variants replace the
native scalar loads with an aligned `uint2` header load, an aligned `uint2`
payload load, or both. Integer unpacking preserves the native values and
all FP32 expressions and accumulation order remain unchanged. The lookup
table and two-row/two-SIMD geometry also remain unchanged.

All 156 IQ4_XS tensors have aligned view offsets and input dimensions
divisible by 256. The 136-byte blocks, row strides, and payload offsets are
multiples of eight. The harness checks these prerequisites at runtime.

Each variant passes 36 guarded matrix cases: six shapes, three kernels
(single, gate/up pair, residual add), and two activation patterns (mixed
values and signed zeros). Every output float is finite and bit-identical
to native; input bytes and output guards are unchanged. Shapes are
256→1, 4352→33, 5120→4097/4111/17408 and 17408→5120. Some reinterpret a
bounded prefix of real tensor bytes, rather than an actual model matrix.
Matrix checks run with Metal API validation enabled.

Paired screening uses two sessions on one engine, ctx512, all 64 layers
on Metal, F16 KV, native FAST/K64/GDN cache64 enabled. The prefix contains
128 synthetic tokens with seed 1. There are 72 alternating AB/BA greedy
forward pairs, with the first eight excluded from timing, and a 30-second
pause before each variant. Numerical checks are outside the forward timer.
The engine receives the `n_threads=4` option; this fully GPU workload does
not establish the CPU helper thread count. API validation is off for timing.

| Loads | Baseline / candidate, token/s | Change | Positive 8-token blocks / 8 |
| --- | ---: | ---: | ---: |
| Header | 8.76929 / 8.72628 | −0.490% | 2 |
| Payload | 8.90683 / 8.89194 | −0.167% | 2 |
| Both | 8.93382 / 8.88730 | −0.521% | 1 |

Every full finite vocabulary is bit-exact after the prefix and every forward;
canonical history, live K/V, DeltaNet and convolution state are exact
before and after the sequence. Each variant executes 10,224 candidate
dispatches: 72 × (96 single + 14 pair + 32 add).

**No variant is adopted.** All initial paired effects are negative; these
short screenings do not establish a stable slowdown or ordinary native
throughput. The absolute rates must not be compared across variants, dates
or against llama.cpp. No native single-session performance campaign or
prefill timing was run for these rejected candidates. The optional test
also supports eight prefixes and checkpoint roundtrips, but those checks
were not run because screening did not justify integration.

Production inference remains unchanged. All 192 timed pairs and 108 matrix
cases are retained with commands, environments, source and binary hashes;
sources and binaries were unchanged during the runs. See the
[manifest](measurements/iq4_loads_2026-10-11/manifest.json),
[derived results](measurements/iq4_loads_2026-10-11/results.json), and raw logs
and source snapshot in the same directory.

```sh
make qw3-iq4-loads-test qw3-iq4-loads-bench
# Clear other QW3/GGML/Metal overrides; v=1 header, 2 payload, 3 both.
QW3_METAL_KV_F16=1 MTL_DEBUG_LAYER=1 ./qw3-iq4-loads-test \
  ../../models/Qwen3.8-27B-UD-Q3_K_XL.gguf 1
# Wait 30 seconds, then run without API validation:
QW3_METAL_KV_F16=1 caffeinate -disu ./qw3-iq4-loads-bench \
  ../../models/Qwen3.8-27B-UD-Q3_K_XL.gguf 1
# Optional full prefix/checkpoint test (not run in this campaign):
QW3_METAL_KV_F16=1 ./qw3-iq4-loads-test \
  ../../models/Qwen3.8-27B-UD-Q3_K_XL.gguf all 1
```
